DevOps Automation Project

Automated CI/CD Pipeline

Automating application validation, Docker image builds, and deployment using Jenkins, GitHub, and Docker.

Project Overview

Project Active

Pipeline Automation

Jenkins executes pipeline stages defined in the project's Jenkinsfile.

Trigger Mechanism

SCM polling checks GitHub for new commits and can initiate a pipeline automatically.

Containerization

Docker packages the web application into an image and runs it in a container.

CI/CD Workflow

1. Source Code Management

Developers update application files and push changes to GitHub.

↓
2. Trigger Detection

Jenkins detects repository changes through SCM polling.

↓
3. Source Validation

The pipeline checks whether the required project files are present.

↓
4. Docker Image Build

Docker builds an image containing the web application and Nginx.

↓
5. Application Deployment

The container runs the application, which can be accessed through the configured local port.

Technology Stack

Version Control: Git and GitHub

CI/CD Automation: Jenkins

Containerization: Docker

Web Server: Nginx

Application: HTML and CSS

Trigger Type: SCM Polling

Project Objective

TriggerFlow demonstrates how DevOps triggers can reduce manual intervention in application delivery. When a new commit is detected, Jenkins can execute the configured pipeline to validate the source, build a Docker image, and deploy the updated application.
